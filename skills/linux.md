# Linux

## Descripción

Skill para administración y desarrollo en sistemas Linux, incluyendo shell scripting y configuración del sistema.

## Conocimientos

- Administración de usuarios y permisos
- Gestión de paquetes (apt, pacman, dnf)
- Scripting bash y shell
- Systemd y servicios
- Networking y firewall
- Administración de procesos
- Gestión del sistema de archivos
