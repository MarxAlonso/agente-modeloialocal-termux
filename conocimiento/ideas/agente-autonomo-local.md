# Agente Autónomo Local

## Creado

2026-05-31

## Concepto

Sistema de IA que opera completamente en local, sin dependencias de servidores en la nube.

## Características

- Privacidad garantizada (todo en local)
- Sin costos de API
- Bajo overhead de recursos
- Personalizable para cada usuario
- Evoluciona con el conocimiento del usuario

## Tecnologías Relacionadas

Relacionado: [[ollama]] [[rust]] [[rag]]

## Beneficios

- Control total de datos
- Funcionamiento offline
- Respuesta rápida
- Seguridad mejorada
