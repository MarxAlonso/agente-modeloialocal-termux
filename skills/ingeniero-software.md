# Ingeniero de Software / Programador

## Descripción

Skill integral para ingeniería de software moderna: diseño, arquitectura, buenas prácticas, testing, patrones y productividad.

## Conocimientos

- Principios SOLID, DRY, KISS, YAGNI
- Patrones de diseño (GoF, arquitecturales)
- Git y flujos de trabajo colaborativos
- Arquitecturas limpias (hexagonal, DDD, microservicios)
- Testing (unitario, integración, E2E, TDD)
- CI/CD y automatización
- Refactorización y deuda técnica
- Code review y pair programming
- Seguridad en aplicaciones
- Performance y optimización
- Diseño de APIs (REST, GraphQL, gRPC)
- Bases de datos (SQL y NoSQL)
