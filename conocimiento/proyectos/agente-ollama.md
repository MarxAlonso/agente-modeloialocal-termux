# Agente Ollama en Rust

## Creado

2026-05-31 14:00:00

## Descripción

Proyecto principal: Agente Autónomo Local para Ollama en Rust.

## Características Principales

- Motor de Memoria persistente
- Sistema de Skills especializados  
- RAG (Retrieval-Augmented Generation) local
- Interfaz REPL interactiva
- Compatible con Termux Android
- Sin dependencias externas de nube
- Comunicación HTTP con Ollama

## Tecnologías

Relacionado: [[rust]] [[linux]] [[termux]]

## Estado

✅ Proyecto completado y compilable con `cargo build --release`
